# Unlimited Bull V1 — Website

React (Vite + TypeScript) website for the client app and Super Admin portal.

## Run

```bash
npm install
npm run dev
```

Open the local URL (usually `http://localhost:5173`).

## Flows

- **Client:** Register → Subscribe / demo access → Dashboard
- **Admin:** Triple-tap logo (register) or Home tab → Admin login
  - Super admin: `mukundimukhuba8@gmail.com` / `admin123`

## Build

```bash
npm run build
npm run preview
```
